# Limitations of Baseline Agent

1. Keyword-Based Intent Detection
- Only matches simple keywords
- Fails for complex or ambiguous queries

2. No Context Awareness
- Cannot remember previous interactions
- Treats each query independently

3. No Real Data Integration
- Does not connect to Terraform Enterprise or APIs
- Responses are static and not grounded in real data

4. No Safety Validation
- Suggestions are not validated for risk or correctness

5. No Explainability or Confidence
- Responses lack reasoning, evidence, or confidence scoring
